# Фильтры и поиск

Carbon: Filtering, Search · Компоненты: `FilterBar`, `SearchField`, `DataTable`, `List`, `StateView`

Как человек сужает список до нужного: по признакам и по словам.

## Когда

- Список длиннее одного экрана, и человек ищет в нём что-то конкретное.

## Когда нет

- Строк меньше десятка — фильтр только мешает.
- Переключение видов экрана — вкладки.

## Из чего

1. Ряд фильтров над списком: признак и его варианты, «все» — сброс.
2. Поиск по словам — в том же ряду.
3. Выбранные фильтры и поиск — в адресе страницы: ссылкой можно поделиться, «назад» возвращает прежний выбор.
4. По фильтру ничего — пустое состояние с «Сбросить фильтры».

## Делай

- Применяй фильтр сразу, без кнопки «Применить», если список отвечает быстро.
- Показывай, что фильтр выбран: человек должен видеть, почему строк мало.

## Не делай

- Не прячь фильтры в окно, если их два-три.
- Не сбрасывай фильтры при возврате на страницу.

## Доступность

- У поиска подпись для читалки; ряд фильтров — группа с подписью; выбранный вариант помечен.

## Чем держится

- Машина: фильтры и поиск живут в адресе (`useUrlFilters`); пустой результат — `StateView` «ничего не найдено».
- Глаз: когда фильтр нужен.
