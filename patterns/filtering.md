# Фильтры

Carbon: Filtering · Источник: carbon-website src/pages/patterns/filtering/index.mdx @ 5e9cd1d · Перевод с английского, Apache-2.0

Компоненты примера: `DataTable`, `FilterBar`, `Heading`, `Section`, `Stack`

Фильтрация — способ, которым человек добавляет или убирает элементы из показанного набора данных, включая и выключая заранее заданные признаки.

Фильтрация даёт человеку добавлять или убирать элементы из показанного набора данных, включая и выключая заранее заданные признаки.

## Обзор

Фильтрация помогает сократить число видимых элементов при работе с большими наборами данных. Фильтры помогают найти то, что человек ищет, увидеть доступные варианты в рамках заданных условий и принять решение, когда вариантов очень много.

## Способы выбора

Верный способ выбора в фильтре делает работу удобнее и быстрее. Carbon поддерживает несколько способов выбора для разных ситуаций. Подумай, какие данные видит человек, чего он хочет добиться и как он мог бы интуитивно сузить данные.

| Способ выбора | Описание |
|---|---|
| Одиночный выбор | Человек может выбрать только один признак, чтобы изменить результаты. |
| Множественный выбор | Человек может выбрать больше одного признака, чтобы изменить результаты. |
| Несколько категорий | Человек может выбирать признаки в нескольких категориях данных. |
| Несколько фильтров с применением пакетом | Человек выбирает несколько фильтров, а потом отдельным действием применяет их. |
| Несколько фильтров с мгновенным обновлением | Данные обновляются при выборе каждого фильтра. |

### Одиночный выбор

Используй фильтр с одиночным выбором, когда человек может выбрать только один признак, чтобы изменить результаты. По сути одиночный выбор ведёт себя как переключатель. Виды фильтров с одиночным выбором:

- обычный выпадающий список;
- выпадающий список в строке;
- набор переключателей (отдельно или в меню).

Пример фильтра с одиночным выбором в выпадающем списке в строке.

### Множественный выбор

Используй фильтр с множественным выбором, когда человек может выбрать больше одного признака, чтобы изменить результаты. По сути множественный выбор ведёт себя как флажки. Виды фильтров с множественным выбором:

- выпадающий список с множественным выбором;
- выпадающий список с множественным выбором в строке;
- набор флажков (отдельно или в меню).

Пример фильтра с множественным выбором в наборе флажков.

### Выбор в нескольких категориях

Категория — набор пунктов фильтра на одну тему. Например, «размер» — категория, а `small`, `medium`, `large` и `extra large` — варианты её фильтра. К одному набору данных можно применить несколько категорий фильтров. Например, человек может фильтровать по размеру, цвету и диапазону цен.

Выбор в нескольких категориях обычно ставят вертикально слева на странице или горизонтально над набором данных. Несколько категорий никогда не кладут в меню или выпадающий список.

Пример нескольких категорий фильтров.

### Несколько фильтров с применением пакетом

Используй пакетный фильтр, когда все фильтры применяются вместе в конце выбора. Набор данных обновляется только один раз, по действию человека. Чаще всего это кнопка «Применить фильтры».

Пакетный фильтр лучше всего подходит, когда человек выбирает много фильтров в разных категориях и на обдумывание может уйти больше времени. Пакетная фильтрация хороша и тогда, когда данные возвращаются медленно: человеку не придётся ждать загрузки после каждого выбора.

Пример пакетной фильтрации.

### Несколько фильтров с мгновенным обновлением

Этот способ возвращает результаты после каждого отдельного выбора. Срабатывает сам выбор, и фильтр меняет данные в реальном времени. Это хорошее решение, когда человек выбирает только в одной категории или ожидается, что он выберет только один фильтр.

## Состояния фильтров

Фильтры в каждой категории должны начинать либо со «всё снято», либо со «всё выбрано». При нескольких категориях начальное состояние может отличаться от категории к категории. Если человек обычно хочет исключить из результатов лишь одно или несколько условий, в начале все фильтры должны быть выбраны. Если человек обычно хочет видеть только результаты по одному условию, все фильтры должны начинать снятыми.

Пример фильтра без выбранных пунктов.

Если фильтры можно спрятать в выдвижную панель, выпадающий список или меню, то на закрытом фильтре должен быть виден признак того, что фильтры применены. Как минимум признак должен показывать число применённых фильтров и давать сбросить фильтры, не открывая контейнер фильтров снова.

Пример фильтра с выбранными пунктами.

## Сброс фильтров

В каждой категории должен быть способ разом сбросить все применённые фильтры, не трогая каждый пункт. Сброс возвращает фильтры в исходное начальное состояние.

Если к одному набору данных применено несколько категорий, должен быть и способ разом убрать все фильтры во всех категориях.
