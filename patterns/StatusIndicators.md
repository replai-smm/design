# Статусы

Carbon: Status indicators · Компоненты: `StatusBadge`, `Icon`, `CountBadge`, `List`, `DataTable`

Статус показывает, в каком состоянии вещь и насколько это срочно.

## Когда

- У строки, карточки, раздела есть состояние, на которое человек реагирует: работает, падает, ждёт решения.

## Когда нет

- Сообщение о случившемся — уведомление.
- Число без срочности — просто число.

## Из чего

1. Тон: опасно · решение · внимание · инфо · нейтрально · хорошо.
2. Знак своей формы у каждого тона (крест, треугольник, галочка, пустой круг) и слово.
3. Слово — из закрытого списка статусов продукта.

## Делай

- Срочное — сверху списка; норма — свёрнута.
- Цвет — только смысл; одинаковый статус — одинаковый тон везде.

## Не делай

- Не передавай статус одним цветом или точкой без слова.
- Не придумывай слово статуса на месте — оно из списка.

## Доступность

- Знак и слово читаются вместе; контраст знака ≥ 3 : 1, текста ≥ 4,5 : 1 в обеих темах.

## Чем держится

- Машина: закрытый список статусов (`statuses.json`), словарь тонов, контраст — тест; своё перечисление тона — красное (устройство `vocab/own`).
- Глаз: срочное сверху.
