# Пилот: «Формы» на @carbon/react против нашей ДС (25.10)

Один экран — паттерн Carbon «Формы» (уведомления: почта, флажок со справкой «i», поля строкой, число, выбор, раскрытие,
ошибка, липкая полоса с кнопками слева) — в двух вариантах с одинаковым содержимым. Всё ниже — замеры этой ветки
(`measure.mjs`, `measures.json`, `shots/`), не по памяти.

- **A** — настоящий `@carbon/react` 1.119.0 + `@carbon/styles`, рядом Tailwind 4; перекрашен под наш облик.
- **B** — наша ДС (Radix + Tailwind 4 + токены Carbon).

текст уведомления переносится; отступ подпись–поле чуть другой; высота страницы на 390 — 968 против 957.

## Вывод

Carbon можно довести до нашего облика, по axe и весу JS варианты равны (JS почти целиком — React). Но A платит
187 строками CSS, привязанными к внутренностям Carbon, обязательным `@layer`, без которого не работает даже раскладка
Tailwind на своих блоках, CSS в 7 раз тяжелее (в 3 раза в gzip) и сверкой снимков при каждом обновлении Carbon — это и
есть «Material-риск».

**Рекомендация:** своя ДС (B) по договору Carbon; Carbon — образец паттернов, токенов и API, не зависимость.
