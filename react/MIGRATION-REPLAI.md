# Replai переезжает на ДС-React — план

Поток П6 Карты 3 (`archive/process-notes-2026-10-05:work/karta-3/CONCEPT.md` §3.4–3.6). Замер 02.10.2026. Только план: код Replai здесь не меняется.
Пакет — `@replai-smm/ds-react` (эта папка). Основа — `design/README.md`: токены, тема Tailwind, сторож «только токены».

## 1. Зачем и что не меняем в этом шаге

- **Зачем.** Сейчас Replai красится шкалами Radix и шрифтом Geist, раскладка собрана классами по месту.
  После переезда облик берётся только из токенов Carbon, раскладка — только из компонентов ДС-React,
  правило «одна главная кнопка» держит сам API. Тогда сторож, контраст и скриншоты (П7) проверяют облик машиной.
- **Что делает этот документ.** Карта «что во что переезжает», нарушения линта по группам, порядок шагов, проверки CI.
- **Чего нет в этом шаге.** Ни одной правки в `replai/frontend`. Код меняют будущие интенты вида «дизайн»:
  первый — с `cells: all` (токены и шрифт задевают все экраны), следующие — с клетками своих экранов.
- **Чего нет вообще в переезде.** Новых действий и правил: новое действие — сначала интент «поведение» (П15).
  Смена порядка в списке («срочное сверху» вместо «по клиенту») — решение договора экрана, не переезда (вопрос 5).

- Шаги отступа вне шкалы Carbon (`1.5`, `2.5`, `3.5`, `5`, `7` …) — 101 место из 830.

## 6. Открытые вопросы владельцу

1. **Цвет группы и темы ответа.** Сейчас это любой цвет из данных (`oklch`, `#hex`), он рисуется точкой. Сделать
   закрытый список из 6–8 цветов Carbon в токенах, а в данных хранить имя цвета? Рекомендую да. Это правка договора
   токенов — её делает интегратор.
2. **Метки статусов Replai.** `StatusBadge` знает только статусы Карты (работает, падает, хотят изменить …). У Replai свои:
   здоровье группы (7 состояний), важность задачи (критично · внимание · спокойно), состояние разговора. Добавить их в
   `statuses.json` со своими словами и одним из четырёх тонов? Рекомендую да. И «спокойно» — это «хорошо» (зелёный)
   или «нейтрально» (без цвета)? Сейчас у него свой зелёный, отличный от «получилось».
3. **Режим просмотра оператора.** Сейчас фиолетовый, чтобы не путать с бедой. В палитре продукта фиолетового нет.
   Синяя плашка «информация» подходит?
4. **Поля ввода.** Поле, выбор, галочка, подпись и тихое текстовое действие в пакет не входят. Оставить их в Replai,
   крашеными токенами (рекомендую), или добавить в ДС-React для дашборда тоже?
5. **Порядок в списках.** `List` умеет «срочное сверху». Но «Все группы» сейчас идут по клиенту, очередь — по времени.
   При переезде оставить нынешний порядок, а менять его отдельным интентом по договору экрана (рекомендую)? Или сразу?
