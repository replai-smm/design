# Дизайн-система — основа

Здесь один источник облика для всех продуктов: цвета, шрифт, отступы, движение и статусы.
Правило одно — **IBM Carbon** (Apache-2.0). Компоненты Replai остаются shadcn/Radix, но красятся только отсюда.
Собрано потоком П6 Карты 3 (`work/karta-3/BUILD-PLAN.md` §2, `CONCEPT.md` §3.4).

Посмотреть всё глазами: открыть `dist/showcase.html` в браузере (на ноутбуке или телефоне — сборка и сеть не нужны).
Там обе темы, ширины 390 и 1280, все статусы и таблица контраста.

## Что здесь лежит

| Файл | Что это | Правят |

## Тема

- Без атрибута — как в системе телефона или ноутбука (`prefers-color-scheme`).
- `<html data-theme="light">` или `data-theme="dark"` — выбор человека. Класс `.dark` (как у shadcn) тоже работает.
- Тему можно задать и куску страницы: `<div data-theme="dark">`.
- Если в системе включено «уменьшить движение», все длительности становятся 0.

## Статусы

Палитр две, у каждой закрытый список цветов (`tokens.json → palettes`):

- **product** — интерфейсы продуктов (Replai, DF-Agency, Arena): четыре тона, таблица ниже;
- **karta** — экраны Карты и дашборд (KARTA-VIEW C-SCR-3): синий — без изменений (`support-info`), жёлтый — хотят
  изменить (`status-warning`), красный — падает (`status-error`). Цвет — у рамки и полосы карточки; слова — обычным
  текстом; серый — не цвет состояния. Какой статус каким цветом — поле `karta` в `statuses.json`
  («работает» — синий, «хотят изменить · удалить · добавить» — жёлтый, «падает» — красный, остальные — без цвета).

Тонов продукта четыре — другого цвета у статуса в продукте не бывает:

| Тон | Цвет | Статусы |
|---|---|---|
| опасно | красный | падает |
| внимание | жёлтый | хотят изменить · хотят удалить · хотят добавить |
| хорошо | зелёный | работает |
| нейтрально | без цвета (серый) | не проверено · ждёт прогона тестов · выключено |

- Слово на экране берётся из закона Карты (`x-say` в `schema/karta.schema.json`), здесь его не придумывают.
  Поменяли слово в законе — тест красный, пока `statuses.json` не догонит.
- У тона три токена: знак (значок, точка, рамка) — `status-error`; текст — `status-error-text`;
  фон метки — `status-error-background`. Так же `warning`, `success`, `neutral`.
- Цвет никогда не один: у каждого тона своя форма значка (крест, треугольник, галочка, пустой круг) и слово.
- Слова облика («нарушен», «экрана нет» и другие, `CONCEPT.md` §3.5) войдут в список, когда их утвердят.

## Контраст

Тест считает контраст каждой пары по формуле WCAG в обеих темах: текст — не меньше 4,5 : 1,
значки и рамки — не меньше 3 : 1. Ниже — PR красный. Пары — из обеих палитр (у Карты — рамка на фоне и слоях).
То же правило договора (G46) считает `tokenProblems()` в `schema/defs/index.mjs`.

Что не проходило раньше и почему теперь проходит:

| Было | Контраст | Стало |
|---|---|---|
| Replai (Radix), светлая: «работает» — зелёный текст на светло-зелёном | 4,21 | `status-success-text` на своём фоне — 5,81 |
| Replai (Radix), светлая: жёлтый текст на светло-жёлтом | 4,24 | `status-warning-text` на своём фоне — 7,11 |
| Replai (Radix), светлая: белый на зелёном, белый на красном | 3,15 · 3,91 | белого на цветном у статусов нет |
| Carbon g10 как есть: жёлтый `support-warning` знаком на фоне | 1,53 | знак «внимание» в светлой — тёмно-жёлтый, 3,02 |
| Carbon g10 как есть: зелёный `support-success` текстом | 3,04 | текст — `status-success-text`, 7,02 |

Тёмная тема проходила и раньше, проходит и теперь.

## Как продукт берёт дизайн-систему

`/update` кладёт копию папки `design/` в продукт (поток П12). Дальше — по продукту:

- **Replai** (Tailwind 4, shadcn/Radix). В главном CSS:
  ```css
  @import "tailwindcss";
  @import "<путь>/design/dist/tokens.css";
  @import "<путь>/design/dist/tailwind.css";
  ```
  Палитра Tailwind и его углы сброшены: `bg-red-500` больше не существует. Есть цвета Carbon
  (`bg-layer-01`, `text-text-secondary`, `bg-status-error-background`) и псевдонимы shadcn (`bg-background`,
  `text-foreground`, `bg-primary`, `border-border`, `ring-ring`). Наборы текста — `text-body-01`, `text-heading-03`.
  Отступы — обычные числа Tailwind; шаги Carbon: 0.5 · 1 · 2 · 3 · 4 · 6 · 8 · 10 · 12 · 16 · 20 · 24 · 40.
  Углы — прямые, как у Carbon; `rounded-full` — у метки статуса.
  Сторож в `eslint.config.js`:
  ```js
  import ds from '<путь>/design/lint/eslint-plugin.mjs'
  export default [{ files: ['src/**/*.{ts,tsx}'], plugins: { ds }, rules: { 'ds/no-raw-values': 'error' } }]
  ```
- **DF-Agency** (ванильный JS) и любые страницы без сборки: подключить `dist/tokens.css` и писать
  `color: var(--cds-text-primary)`, `padding: var(--cds-spacing-05)`. Шрифт подтянется сам из `fonts/`.
  Сторож — из командной строки, ESLint не нужен: `node design/lint/cli.mjs <папка>`.
- **Дашборд** и **Replai** — компоненты ДС-React (`react/`: Radix, раскрашенный токенами, истории Storybook, a11y):
  как подключить — `react/README.md`; план переезда Replai — `react/MIGRATION-REPLAI.md`.
- **Arena** остаётся на VKUI: облик — через переходник `dist/vkui-adapter.css` (копия в `arena/web/design/`, включается сборкой `ARENA_THEME=rsmm`, интент Арены `I-vkui-rsmm-theme`). Контраст переходника на заливках так, как их ставят компоненты VKUI, держит `__tests__/vkui.test.ts`.

### Сторож «только токены»

Ловит сырые цвета (`#fff`, `rgb(…)`, `oklch(…)`), произвольные значения Tailwind (`w-[24rem]`, `text-[15px]`)
и классы палитры (`bg-red-500`). Ссылки на токены (`bg-[var(--cds-layer-01)]`) и варианты (`data-[state=open]:`) можно.
Если сырой цвет правда нужен (например, фирменный цвет кнопки VK), строка помечается `ds-allow: <причина>` —
без причины пометка не действует.

Старые нарушения не чинят разом — включают **храповик**:
```
node design/lint/cli.mjs --baseline ds-baseline.json --write src   # записать нынешние числа
node design/lint/cli.mjs --baseline ds-baseline.json src           # в CI: по файлу не больше, чем записано
```
Число по файлу может только падать. Замер на Replai 02.10: 66 нарушений (34 произвольных значения, 32 сырых цвета).

## Как поменять токен

1. Интент вида «дизайн» с клетками `cells: all` — правка токена задевает все экраны всех продуктов.
2. Поправить `tokens.json` или `scale.json` (цвет — только из палитры Carbon; новый тон, новая палитра или новая
   шкала — только через договор `schema/defs/tokens.json`, его меняет интегратор).
3. `node design/build.mjs` — пересобрать `dist/`.
4. `npx vitest run design` — контраст, форма, статусы, свежесть `dist/`, шрифт. Красное — не мержится.
5. Открыть `dist/showcase.html` в обеих темах на телефоне и ноутбуке.
6. `/update` разносит новую копию по продуктам; их скриншоты покажут, что поменялось.

## Откуда значения

- Цвета: `@carbon/themes` 11.82.0 (темы g10 и g100, плюс кнопки и фоны уведомлений). Токены `status-*` — наши,
  значения из палитры Carbon (`@carbon/colors` 11.59.0) и меток Carbon (`tag-*`).
- Отступы и размеры: `@carbon/layout` 11.60.0. Текст: `@carbon/type` 11.68.0. Движение: `@carbon/motion` 11.53.0.
- Наше дополнение: `duration-move` = 0,6 с и `easing-move` — правило «карточка едет или раскрывается за 0,6 с,
  соседи не прыгают».
- Шрифт: `@ibm/plex-sans` 1.1.0, файлы `complete/woff2`, лицензия SIL OFL 1.1 (`fonts/OFL.txt`).
